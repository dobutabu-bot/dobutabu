## Operasyon Takvimi

### Gunluk

- `/api/health`: HTTP 200, V5.0.2, production, database ok, storage ok.
- `Production R2 Backup` son basarili run yasi en fazla 26 saat.
- Backup workflow fail veya 26 saatten eskiyse kritik uyari.

### Haftalik

- Son yedi gunde en az bir basarili R2 backup oldugu dogrulanir.
- Daily/weekly/monthly retention siniflari ve son workflow sonucu kontrol
  edilir.
- Secret degerleri, belge icerigi ve kullanici verisi rapora alinmaz.

### Aylik

- GitHub Actions uzerinden kontrollu baseline backup tetiklenir.
- Backup izole gecici alanda decrypt edilir.
- `PRAGMA integrity_check = ok`, kayit sayimlari ve 1.017 dosyalik belge
  manifesti dogrulanir.
- Production volume uzerine restore yapilmaz.

## 14 Gunluk Gozlem

Her gun salt okunur olarak health, login erisimi, son backup yasi, ana PDF
download davranisi, main/deployment baseline'i ve kritik CI durumu kontrol
edilir. Bulgular kullanici verisi icermeden PASS/FAIL olarak kaydedilir.

Gozlem doneminde:

- Yeni feature deploy edilmez.
- Baseline tag tasinmaz.
- Kritik fail varsa otomatik olarak READY durumu geri cekilir ve hotfix
  proseduru baslatilir.
